# PWA и GitHub Pages: что сделано и как обновлять

Дата: 2026-10-06. Адрес: https://sdlm.github.io/LettersWarmUp/

## Что сделано

- Репозиторий выложен на GitHub (публичный), добавлена лицензия MIT.
- Приложение стало PWA: манифест, иконки «Аа», service worker (`src/sw.js`).
  После первого открытия работает без сети, ставится на главный экран,
  не даёт экрану гаснуть, цвет системной панели следует теме.
- `dist/index.html` по-прежнему работает, если открыть его с диска.
- `build.py` собирает в `dist/` всё нужное и проверяет, что файлы из
  кеша service worker на месте. Версия кеша — хеш содержимого `dist/`.
- GitHub Actions (`.github/workflows/pages.yml`) выкладывает `dist/` на
  Pages при каждом push в `main`.
- Иконки рисует `swift tools/make_icons.swift`, готовые PNG лежат в `src/icons/`.

## Как выпустить новую версию

1. Правки — в `src/`.
2. `python3 build.py`. Без этого шага задеплоится старая версия, и никто не предупредит.
3. Тесты: `node --test` и `python3 -m unittest discover -s tests -p 'test_*.py'`.
4. Закоммитить `src/` вместе с `dist/` и сделать push в `main`.
5. Через минуту-две сайт обновлён. Проверить: `gh run list --workflow pages.yml --limit 1`.

## Как обновление доходит до телефона

Ничего переустанавливать не нужно.

- Первый запуск после деплоя (с сетью) ещё показывает старую версию и
  в фоне скачивает новую.
- Со следующего запуска видна новая.

Чтобы получить её сразу: открыть приложение с сетью, полностью закрыть
(смахнуть из списка запущенных) и открыть снова.

Без сети телефон продолжает работать на последней скачанной версии.
